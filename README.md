# 4K-Capture
### Requires Microsoft .NET 8 Desktop Runtime if it is not already installed on the device.

### 4K Capture is a Windows desktop app for low-latency live preview and recording from capture cards (Samsung Dex, TV Box, Stream game....) and webcams.

### It is designed for fast everyday use: choose your video device, pick a video mode, monitor audio, and start previewing immediately. 

### It works well for capture workflows involving game consoles, cameras, TV boxes, and other HDMI sources connected through a compatible capture card. 

### You can switch between fullscreen and always-on-top mini overlay, adjust volume directly over the preview area, and save recordings to MP4.

### Key features:
#### - Low-latency live preview for capture cards and webcams recognized by Windows
#### - Quick switching for video devices, audio input devices, and output devices
#### - Automatic and manual video mode selection for resolution and FPS
#### - Fullscreen mode and always-on-top mini overlay
#### - MP4 recording from the active preview
#### - Adjustable volume from 0% to 300%
#### - Preview scaling modes: Fit, Fill, and Stretch
#### - Live FPS monitor
#### - Bilingual interface: English, Vietnamese, Chinese, Russian
#### - Optional Android TV remote tools over ADB, including scan, connect, navigation keys, media keys, and text input
#### - Saved preferences for devices, video mode, aspect ratio, language, and remote endpoint

### 4K Capture is intended for local desktop use on Windows 10/11 with compatible capture hardware.
