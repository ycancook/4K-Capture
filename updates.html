Update Log

Recent changes and improvements for the 4K Capture application.

Release History

v1.0.7.0 2026-08-13

  • Fixed minor functional issues and strengthened the user interface.
  • Added support for additional application languages.

v1.0.6.0 2026-07-20

  • Added Mini Floating Remote: Quick TV control directly on the video frame with smart auto-hide behavior.
  • Dynamic Scaling: The mini remote automatically resizes proportional to the window size, perfect for Picture-in-Picture mode.
  • Sleek Design: Modern rounded capsule interface that tightly hugs the buttons for a refined look.
  • Added app shortcut pinning on the Mini Remote and fixed several minor bugs.
  • Updated Usage Guide: Added important notes on enabling Developer Options and ADB on TV for Remote usage.

v1.0.5.0 2026-06-25

  • Added snapshot capability for live video and refined keyboard shortcuts for a smoother experience.
  • Integrated File Manager for Remote ADB: Browse, select, and play music/videos directly on your TV or Android devices.
  • Support for continuous playlist playback on ADB-connected devices.
  • More exciting features and improvements are on the way! Thank you for purchasing and supporting our application!

v1.0.4.0 2026-06-15

  • Fully resolved black flickering issues when the app window overlaps video playback in browsers (YouTube, Facebook, etc.).
  • Added the ability to switch Remote position (Left/Right) and optimized the UI to prevent blocking TV content.
  • Introduced List View mode for apps and a dedicated filter for system applications.
  • Improved uninstallation: Added support for system apps and preserved scroll position after removal.
  • Added customizable keyboard shortcuts that can be modified directly within the Usage Guide.

v1.0.3.0 2026-06-04

  • Fixed screen flickering issues when running alongside video game applications.
  • Optimized the virtual remote, adding features to make it behave more like a real hardware remote.
  • Automatically detects Webcams and disables live monitoring to prevent audio feedback.
  • Optimized audio latency (Low Latency) to achieve the best 1:1 sync between video and audio.
  • Fully resolved black flickering issues when app window overlaps browser video playback areas.

v1.0.2.0 2026-04-22

  • Usage Guide and Update Log now auto-hide when entering Mini overlay, and those menu actions are disabled there to prevent accidental opens.
  • Mini overlay now remembers its last position and size for the current app session, then resets to the default layout after the app is closed.
  • Fixed the loading cursor that could appear when returning from Mini overlay to the normal window.
  • Improved transition stability when switching between Mini overlay and the standard window.
  • Added Ctrl+H as a quick shortcut to hide the app to the taskbar. Pressing Ctrl+H while the app is hidden now restores the window.
  • In Mini overlay, Ctrl+H now works as a global hide/restore hotkey even while you're using another app.

v1.0.1.0 2026-04-18

  • Improved capture recording reliability for webcams and compatible capture cards.
  • Fixed microphone selection and audio routing to reduce missing audio, duplicate audio, and echo.
  • Added Monitor Mode options: Off, Program only, Mic only, and Program + mic.
  • Added a clearer Usage Guide with Quick Start, audio notes, and app version display.

v1.0.0.0 2026-04-17

  • First Microsoft Store release of 4K Capture.
  • Low-latency preview and MP4 recording for compatible capture devices and webcams.
  • Quick device switching, fullscreen, mini overlay, volume controls, and optional Android TV remote.
